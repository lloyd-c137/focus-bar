# 01 · Focus Bar V1 产品需求文档

状态：设计 / 未实现 · 更新：2026-11-22

## 1. 定位

Focus Bar 是 **macOS 菜单栏中的手动每日任务/日程清单**。用户自行添加事项、指定日期与可选时间；应用按日期归档、展示、勾选完成。界面极简、系统原生，除了管理事项之外不引入其他复杂工作流。

**V1 不自动创建任务，也不接入 AI、外部日历或 GitHub。** 此决定替代此前“每天自动生成 Focus”的方案。

## 2. 核心用户旅程

`点击菜单栏 → 看 Today → + 新增事项 → 默认今天/可更改日期或时间 → 勾选完成 → 关闭`

所有操作直接在菜单栏面板完成（偏好配置可在独立 Settings）；不做全屏任务管理应用。

## 3. 主要功能

| ID | 要求 | 说明 |
| --- | --- | --- |
| P-01 | 菜单栏常驻 | 默认单色图标，可选显示未完成数 |
| P-02 | 今日视图 | 展示所选本地日期的事项，不限定条数；超长列表内部滚动 |
| P-03 | 手动快速新增 | 最少只填标题，日期默认 Today；时间可选 |
| P-04 | 日程安排 | 新增/编辑时选择日期、可选具体时间，支持全天（不填具体时间） |
| P-05 | 日期切换 | Today、Tomorrow、日期选择器；跳转回 Today |
| P-06 | 完成及撤销 | 单击复选框，立即持久化；当天可撤销 |
| P-07 | 编辑与删除 | 改标题、说明、日期、时间；确认危险删除 |
| P-08 | 逾期提醒区 | 过期未完成的非重复事项在 Today 顶部列出，不暗中调整原日期 |
| P-09 | 可选重复事项 | V1 提供每日/每周重复模式；各日期完成状态分离 |
| P-10 | 排序 | 逾期优先，已定时间按时间升序，无时间按手动顺序，已完成折叠 |
| P-11 | 本地历史与离线 | SwiftData 本地保存，任意时刻可查看已创建日期的事项 |
| P-12 | 系统一致性 | Light/Dark、SF Symbols、系统材质、键盘、VoiceOver、减少动态效果 |
| P-13 | 登录启动 | 用户可选择打开登录时启动 |
| P-14 | 空状态和恢复 | 空列表有简洁提示与添加入口；保存/迁移失败明确提示 |

### 不做的功能

- AI 生成、自动排序、外部来源采集、智能推荐。
- GitHub、macOS Calendar、Reminders 等同步；不需要 API 密钥。
- Start Focus / 计时器 / 专注时长统计 / 桌宠。
- 用户账号、云同步、多人协作、复杂标签层级、项目管理、统计 Dashboard。

## 4. 日期与时间语义

- **事项日期是计划处理日**（本地日历日）。默认为创建当天，但允许过去/未来日期。
- **具体时间可选**：如果填写，视为该日预期处理时间，不强制解释为截止时间。
- 不把“计划在下午做”当作“下午必须完成”；V1 不单设复杂 Deadline 体系。
- 所有相对日期（今天、明天）随系统时区和本地日期计算；调整时区时保持用户选定的日历日。
- 日期已过去且未完成的单次事项保留原日期，出现在 Today 的 Overdue 区；用户显式改期才改变原计划。
- 重复事项按规则生成每日期实例；完成一个实例不影响下一天。
- 无时间事项的排序由创建顺序/用户手动排序决定。V1 可先实现稳定创建顺序，显式拖动排序为后续增强。

## 5. 交互细节

### 查看 Today
Header 为 `Today` + 日期；有日期切换入口。分区：`Overdue`（如有）、`Scheduled`（有时间）、`Anytime`（无时间）、`Completed`（折叠，若有）。
避免单纯为了分类而多出大量标题：某个分区为空时不显示。

### 创建事项
点击底部 `+` 后，内联输入标题；Enter 保存，Esc 取消。高级字段按需展开：日期、时间、说明、重复规则。支持中文输入法组合态，不得在候选词未确认时误提交。

### 编辑操作
点击标题/右键编辑；右键菜单还包含 Move to Tomorrow、Change Date、Delete。必须有明确的删除确认或可靠 Undo；“完成”不等于删除。完成项弱化并折叠，仍可撤销。

### 空状态
“Nothing scheduled for today.” + Add task。没有数据时不展示虚构事项，不自动提示连接 AI。

## 6. 非功能要求

- **运行**：macOS 原生菜单栏应用，不需长期打开主窗口；关闭弹层不退出程序。
- **离线**：全部核心功能不联网。
- **可靠**：完成、编辑、删除不会丢状态；数据库写入失败要可见，不假装成功。
- **性能**：一般列表应立即响应，长列表滚动平滑，禁止无意义后台轮询。
- **隐私**：无网络依赖，不申请日历读取、屏幕录制或辅助功能监视权限。
- **美学**：简洁排版、系统语义色、SF 字体、SF Symbols、原生窗口行为。

## 7. V1 成功判据

- 在 Mac 上 10 秒内可以新增一条“今天”的事项（交互目标，非已测数据）。
- Today、Tomorrow、指定日期的切换准确；手动设置日期不会丢失。
- 3、20、50 条任务均能操作，长列表内部滚动。
- 任务勾选后重启应用仍保留。
- 无互联网时所有核心功能正常。
- 没有 AI、Start Focus、计时器、桌宠和多余的统计面板。
