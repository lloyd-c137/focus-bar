# 01 · Focus Bar 产品需求

状态：2026-11-25 产品决策更新

## 1. 定位

Focus Bar 是一款本地优先的 macOS 菜单栏长期待办清单。用户添加事项后，事项会一直留在清单里，直到完成或删除。

**事项没有计划日期。** 应用不提供 Today / Tomorrow / 指定日期导航，不会因为创建日期或历史日期把事项自动变成逾期。

截止日期（DDL）是独立的可选字段，默认不设置。只有用户显式设置了 DDL 且日期已过，未完成事项才进入 Overdue。

## 2. 核心用户旅程

`点击菜单栏 → 查看事项 → 快速添加标题 → 可选截止日期、时间或重复 → 完成事项`

全部任务操作在原生菜单栏面板完成。核心清单本地离线可用；用户明确配置后，应用将本地数据库快照同步到其 GitHub 私有备份仓库。不接入 AI 或外部日历。

## 3. 主要功能

| ID | 要求 | 说明 |
| --- | --- | --- |
| P-01 | 菜单栏常驻 | 单色图标，可选显示未完成数量 |
| P-02 | 长期事项清单 | 展示所有未完成单次事项，不按日期筛选 |
| P-03 | 快速新增 | 只输入标题即可保存；DDL、时间、重复规则按需设置 |
| P-04 | 可选截止日期 | 默认无 DDL；创建和编辑时可设置或清除 |
| P-05 | 时间信息 | 可选时刻，用于显示和排序，不包含日期，也不触发提醒 |
| P-06 | 完成与撤销 | 单击勾选，状态持久化；完成项可折叠和撤销 |
| P-07 | 编辑与删除 | 改标题、备注、DDL、时间；删除可撤销 |
| P-08 | Overdue | 仅未完成且显式 DDL 早于本地今天的事项进入 Overdue |
| P-09 | 重复事项 | 每日或每周重复；每次实例的完成状态独立 |
| P-10 | 稳定排序 | Overdue 按 DDL 排序；有时间事项按时刻排序；无时间事项按稳定顺序排列 |
| P-11 | 本地历史与离线 | SwiftData 本地保存；离线可操作；可选 GitHub 私有仓库备份 |
| P-12 | 系统适配 | Light/Dark、键盘、VoiceOver、Reduce Motion |
| P-13 | 登录启动 | 用户可在设置中控制 |

## 4. 日期与时间语义

- 事项没有计划日期，也没有“移动到今天/明天”操作。
- 新增单次事项后，它始终留在清单里，直到用户完成或删除。
- DDL 是唯一能让单次事项进入 Overdue 的日期；没有 DDL 的长期事项永不因时间流逝自动逾期。
- 时间是可选的时刻标签，不附着到某一天，不自动提醒。
- 每日/每周重复规则按当前本地日期生成实例。每周事项显式选择星期；完成状态按 occurrence 保存。
- 重复 occurrence 的可选 DDL 仅作用于对应实例。
- 系统日期变化只更新当前重复实例、DDL 状态和菜单栏计数，不修改事项本身。

## 5. 主面板与交互

Header 显示 `Tasks` 和更多操作，不显示日期导航。

列表分区：

- `Overdue`：已过 DDL 且未完成的事项。
- `Scheduled`：有时刻、但尚未逾期的事项。
- `Anytime`：没有时刻的事项。
- `Completed`：已完成事项，默认折叠。

点击底部添加框后输入标题并按 Return 保存。可选设置截止日期、时间和重复规则；按 Esc 清空未保存输入。中文输入法候选确认不能误提交。

右键菜单提供编辑、重命名、删除和重复事项作用范围。不提供更改计划日期或按日期跳转。

## 6. 非功能要求

- 使用 Swift、SwiftUI、必要时 AppKit、SwiftData 和 SF Symbols。
- 核心任务操作离线可用；每次成功写入后触发 GitHub 备份，离线时保留待同步并在网络恢复后重试。
- 备份未经加密，只上传至专门的私有数据仓库；GitHub 凭据保存在 macOS Keychain。
- 保存失败必须明确反馈，不清空输入。
- 旧版事项的已保存内容、完成状态和 DDL必须保留；旧版计划日期不再影响显示或状态。
- 轻量清单布局支持长列表滚动，不使用 WebView 或 Dashboard。

## 7. 验收判据

- 没有任何计划日期选择器、日期导航或改期入口。
- 新建无 DDL 事项后，它出现在长期清单；跨日后仍在清单且不逾期。
- 设置未来 DDL 的事项保持正常；DDL 过去后未完成事项进入 Overdue。
- 完成、撤销、编辑和重启后状态正确。
- 每日/每周重复事项按规则出现，实例完成状态独立。
- 现存数据不丢失，旧计划日期不再产生 Overdue。
