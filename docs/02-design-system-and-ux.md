# 02 · Focus Bar 原生 macOS 设计与交互规范

状态：2026-11-25 产品决策更新。主面板是一张长期清单，不是日历视图。

## 1. 视觉方向

- 使用 SF 系统字体、语义颜色、SF Symbols、原生窗口材质。
- 一行一项，不堆多层卡片、彩色优先级、统计或装饰动画。
- 支持 Light/Dark、提高对比度、减少透明度、Reduce Motion、键盘和 VoiceOver。

## 2. 信息架构

菜单栏图标简洁单色，可选显示未完成数量。主面板约 340pt 宽，列表独立滚动，新增入口固定在底部。

```text
┌───────────────────────────────────┐
│ Tasks                       ···   │
│                                   │
│ OVERDUE                           │  [仅有已过 DDL 的事项时]
│ ○ Submit draft          Due Nov 20│
│                                   │
│ 10:30                             │  [有时间才显示]
│ ○ Discuss project                 │
│                                   │
│ ANYTIME                           │  [有无时间事项时]
│ ○ Read 30 minutes                 │
│                                   │
│ ▸ COMPLETED (2)                   │
│ ───────────────────────────────── │
│ + Add a task                  ⚙   │
└───────────────────────────────────┘
```

### 日期语义

- 不显示 Today 日期、日期选择器、前后日期按钮或改期动作。
- 事项长期留在清单中；DDL 是用户主动选择的唯一截止日期。
- Overdue 日期文字来自 DDL，不显示或读取旧计划日期。

### 新增事项

- 底部输入框只要求标题，Return 保存，Esc 清空草稿。
- 快速字段：截止日期、时刻、重复规则。
- 每周重复提供星期选择。备注和已有事项详情通过信息按钮编辑。
- DDL 默认无；设置后可以清除。
- 中文输入法候选态 Return 不得误提交。

### 任务行

- 复选框立即持久化，完成项进入可折叠 Completed。
- 右键菜单提供 Edit Details、Rename、Delete；重复事项提供仅删除本次或删除系列。
- 不提供 Move to Today、Move to Tomorrow 或 Change Date。
- 有时刻的任务显示时刻；设置 DDL 的任务显示 `Due …`。无 DDL 的任务不显示日期。

## 3. 设计 Tokens

| 元素 | 方向 |
| --- | --- |
| 容器边距 | 约 12–16 pt |
| 主标题 | 系统字体 Semibold |
| 任务标题 | 系统正文色，最多两行 |
| 次信息 | secondaryLabel，DDL 过期时使用系统红色 |
| 分割线 | 原生 separator、低对比度 |
| 强调色 | 系统 Accent Color |
| 圆角/阴影 | 交给系统窗口材质 |

## 4. 交互与微动画

- 完成/撤销立即反馈；数据库失败显示错误，不假装成功。
- 不使用弹跳、音效或庆祝动画。
- 列表变化简短、柔和，并尊重 Reduce Motion。
- Esc 取消未保存草稿；Tab/Shift+Tab 浏览控件；Space 勾选；Return 保存（兼容 IME）。
- 点击窗口外关闭不影响已保存事项。

## 5. 全状态

| 状态 | UI |
| --- | --- |
| 空清单 | “No tasks yet. Add one below.” |
| 全部完成 | 显示完成提示，可展开 Completed |
| Overdue | 只显示过期 DDL 的未完成事项 |
| 长列表 | 列表内部滚动，底部新增入口保持可访问 |
| 标题特别长 | 自动换行/详情编辑 |
| 存储失败 | 明确错误提示，不静默清空数据 |
| Light/Dark | 系统色与材质适配 |
| 键盘/VoiceOver | 主要事项操作均可访问 |

## 6. 明确排除

不显示计划日期、日期导航、按日归档、改期入口、AI、Start Focus、计时器、桌宠、统计面板、GitHub 任务集成或 Calendar 集成。备份状态只在 Settings 中展示。
