# 02 · UI/UX 与 macOS 设计系统

版本 V1.0 · 目标：**看起来像 macOS 自身的一部分，而不是套在菜单栏里的网站**。

## 1. 设计原则

1. **Native over novelty**：系统原生控件、材质、菜单、焦点与快捷键优于自造控件。
2. **Clarity over density**：一行一事，视觉层级明确；不给每个任务塞标签和统计。
3. **Quiet over gamification**：不使用连续签到、火焰、惩罚、时间追踪、弹窗催促。
4. **Typography is the interface**：主要依赖字体、间距、对齐表达层次。
5. **Action on demand**：通常只显示复选框和标题，更多操作通过悬停/右键/菜单访问。
6. **System-adaptive**：随外观、系统强调色、文本对比度、减少动画等偏好变化。

## 2. 应用整体形态

- 常驻菜单栏图标，推荐使用单色 SF Symbols 风格的简约列表/目标符号；图标作为模板图像以适配菜单栏颜色变化。
- SwiftUI `MenuBarExtra` + `.menuBarExtraStyle(.window)` 为默认技术路线。
- 不展示主 Dock 图标（可考虑 `LSUIElement`），但必须验证 Settings 的激活行为、系统退出和登录启动机制；不要为了隐藏 Dock 牺牲辅助功能。
- 主面板默认宽 360 pt，建议可在 340–390 pt 范围内根据实际布局调整。内部动态高度，最大不超过当前屏幕可用高度的合理比例（例如 75%），清单滚动。
- 不自行实现整个 window chrome；尽量使用系统视觉与原生阴影/材质。
- 独立原生 Settings 场景，允许目标编辑、源授权、外观和隐私配置。

## 3. 信息布局 / 线框

```text
┌─────────────────────────────────────┐
│ Today                         ···   │
│ Sunday, Nov 22                      │
│                                     │
│ 3 remaining             2 completed │
│                                     │
│ MUST DO                             │
│ ○ Submit the assignment             │
│   Today · 16:00                     │
│                                     │
│ PRIORITIES                          │
│ ○ Review project milestone          │
│ ○ Prepare next XC decisions         │
│                                     │
│ ROUTINE                             │
│ ○ Read for 30 minutes               │
│                                     │
│ ▸ COMPLETED (2)                     │
│ ─────────────────────────────────── │
│ + Add a task           ↻  Settings │
└─────────────────────────────────────┘
```

仅示意内容结构，不能把示例文字作为真实任务来源。

### Header
- 主标题 Today 使用系统字体与 Semibold，24pt 以下依可读性调节；次级日期为系统 secondaryLabel。
- 更多菜单包含“刷新”“查看历史”“设置”“退出 Focus Bar”；不要把所有操作常驻在顶栏。
- 显示最后更新状态仅在必要时（如缓存过期或连接失败）出现，不占用正常屏幕空间。

### Task Row
- 默认行高视内容而定，建议最小点击目标达到易操作的高度（约 32–36pt），长标题允许最多两行并在需求许可时展开全文。
- 复选框为单一主要操作，完成瞬间反馈并保存；不需打开任务详情才能勾选。
- 标题文字一般 13–14pt 系统语义字号，副信息 11–12pt。
- 仅在来源确切、截止时间明确时展示 Deadline；无截止任务不显示假占位。
- 鼠标右键展示原生 Context Menu；键盘聚焦时相同操作可用。
- 优先级用位置表达，避免大量亮色 Badge。
- 用户编辑的任务不能被同步数据覆盖，若外部资料变化应提示差异供用户处理。

### 分组与排序
- Must Do：已确认的当日到期或必须履行的事项。
- Priorities：今天最值得推进但无强制截止的事项。
- Routine：明确设置的固定习惯。
- 没有的分组不显示。完成任务默认滑入 Completed 折叠组，提供撤销。
- 面板可容纳 4–6 项时不应显得拥挤；20 项则内部滚动，不截断数据。

### 底部
- 主要控件：`+ Add a task`，点击后原地展开单行输入。
- 次要入口：刷新、设置；尽量使用溢出菜单而非三个相邻的显眼按钮。
- **绝不出现 Start Focus、Play、计时器按钮。**

## 4. 颜色、字体与组件

**避免硬编码浅色背景。** 应使用 macOS 语义系统色和材质：

| 用途 | 推荐做法 |
| --- | --- |
| 主文字 | `primary` / 系统 label color |
| 次要文字 | `secondary` / secondaryLabel |
| 面板背景 | 系统材质/原生窗口背景 |
| 分割线 | 低对比度系统 separator |
| 完成状态 | secondary + strikethrough，避免刺眼色 |
| 强调动作 | 跟随系统 Accent Color，少量使用 |
| 图标 | SF Symbols，尺寸/weight 与文本匹配 |
| 字体 | 系统 San Francisco / Dynamic Type 可适配配置 |

不使用：固定明暗色板覆盖系统、霓虹色、大面积渐变、卡片套卡片、拟物拟声庆祝动画、强营销风格空状态。

### 间距建议（可按视觉测试微调）
- 外边距 16pt。
- Header → 摘要 12–16pt。
- 分组标题与首行距离 8pt，组间 16–20pt。
- 行内左右对齐基线，Checkbox 与正文间距约 10–12pt。
- 面板圆角和阴影交由系统，局部背景尽量不另加多层边框。

## 5. 动效与反馈
- 点击复选框：立即视觉反馈，保存后状态持久化，动画约 120–200ms，失败则明确提示并恢复状态。
- 刷新：低干扰的状态提示，不阻塞用户读清单。
- 新建议事项：在现有列表中温和出现，可暂存在“新建议”区，不能突然改变用户操作对象的位置。
- 无需跳跃、弹跳或烟花。
- 遵从 Reduced Motion；无动画也不影响语义。

## 6. 交互与键盘
- 点击菜单栏图标打开面板，点击窗口外自然关闭。
- 支持 Tab/Shift+Tab、Space 勾选、Enter 提交输入、Esc 取消输入/关闭当前弹层；具体与系统控件冲突应按 macOS 惯例处理。
- 快捷添加默认建议 `Option + Space`，必须先检测冲突并允许完全关闭/重新映射；全局热键注册失败不得妨碍正常使用。
- 使用系统原生的右键菜单和文本编辑行为（选中、复制、撤销等）。
- 完成任务时不改变滚动位置或突然收起焦点所在行，应在安全时机更新/折叠。

## 7. 全部 UI 状态

| 状态 | 呈现 |
| --- | --- |
| 正常有任务 | 按分组排序的完整列表 |
| 全部完成 | “You're all caught up.” + 随时新增入口 |
| 首次无数据 | “No tasks yet” + 添加目标/连接来源入口 |
| 未授权日历 | 只在设置和相关提示处说明，不遮盖日常使用 |
| AI 未配置 | 规则模式照常使用，Settings 可启用 AI |
| 离线 | 使用上次缓存，不显示虚构的最新状态 |
| 数据正在同步 | 轻量状态提示，保持当前列表可操作 |
| 同步失败 | 底部非阻断错误与重试入口，保留旧数据 |
| 冲突/重复 | 不展示重复事项，必要时进入待确认建议 |

## 8. 无障碍与本地化
- 完整 VoiceOver 标签（例：“Mark as completed, task title”），反馈完成状态。
- 支持键盘全流程、系统对比度增强、深色模式、减少动态效果。
- 避免靠颜色唯一表达状态；Deadline 使用清晰文字。
- 布局适应中英文任务标题与缩放文本。
- V1 至少保障简体中文与英文文案可本地化，不将界面文字写死在业务逻辑中。

## 9. 视觉验收基线

评审提供 Light/Dark 截图：空、3项、10项、20项、全部完成、长标题、编辑、同步错误、设置、VoiceOver 导航。目标不是精确复刻某款第三方软件，而是使用原生控件、系统间距和清晰排版达到“macOS 自带工具”的一致性。
