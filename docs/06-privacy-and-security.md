# 06 · Focus Bar 隐私、安全与可靠性

状态：本地优先；用户修改后向私有 GitHub 备份仓库同步未加密快照。

## 1. 隐私边界

Focus Bar 只保存用户手动输入的标题、备注、可选截止日期、时刻、重复规则和完成状态。没有计划日期，也不会自动收集数据。

不调用 AI、Calendar、Reminders、邮件或通讯录；不使用应用云端账户、远程任务数据库或遥测。唯一的网络功能是向专用私有 GitHub 备份仓库上传本地 SQLite 快照。

## 2. 本地数据

| 类型 | 保存内容 | 访问策略 |
| --- | --- | --- |
| Task | 标题、备注、可选 DDL/时刻、重复规则、完成状态 | 应用私有 SwiftData Store |
| Occurrence | 重复系列的本地日期实例状态和字段覆盖 | 应用私有 SwiftData Store |
| Preferences | 菜单栏计数、登录启动、完成项显示 | 本地设置 |
| GitHub Backup | 完整 SQLite 快照，含任务标题、备注、日期、重复与完成状态 | 私有 GitHub 仓库，未加密；每次成功修改后覆盖当前快照并生成 Git commit |
| GitHub token | 仅用于备份仓库 Contents 读写 | macOS Keychain；不得写入应用设置、日志或仓库 |
| Diagnostics | 必要错误类型、版本和时序 | 本地且脱敏 |

任务标题和备注可能包含敏感信息。日志不得记录完整任务文本或数据库内容。

旧版 SwiftData 计划日期列只保留以兼容原有数据库，不再决定任务显示、排序或 Overdue 状态。

## 3. 数据可靠性

- 写入失败时显示错误，不允许 UI 误报成功。
- 完成和撤销状态在重启后保持。
- 删除支持 Undo；删除系列与单次重复实例作用范围明确。
- 迁移或存储失败时不得静默清空数据库。
- 离线状态下所有核心操作照常。
- 上传失败时本地数据仍然保存，保留待同步状态，并在网络恢复时重试。
- 备份采用 SQLite 在线备份接口读取活动数据库，避免直接复制 WAL 中的数据时得到不完整快照。
- 不将真实数据库或个人任务样本提交到 Focus Bar 源代码仓库；真实数据只进入用户创建的私有备份仓库。
- 用户选择明文备份；有仓库访问权限的人可以读取日程信息。

## 4. 发布与构建

本地 bundle 使用 ad-hoc 签名，未公证且不用于分发。GitHub 备份使用 HTTPS API，不添加第三方 SDK。
