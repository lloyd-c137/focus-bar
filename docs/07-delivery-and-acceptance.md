# 07 · 开发路线、交付与验收标准

状态：计划，仅文档。不得将以下 M 阶段描述成已完成。开发优先保证 **每天自动出现可信清单**，不是 UI Demo 的炫技。

## 1. 里程碑

### M0 · 原生框架与菜单栏体验（可运行、非 AI）
交付：可打开的 Xcode 工程、MenuBarExtra window 风格面板、Settings 场景、图标、原生视觉、假数据夹具、可勾选的 Task 行、SwiftData 基础存储、基本测试。

验收：
- App 启动后仅在菜单栏显示，不需要 Dock 主窗口。
- 点击图标显示清单，点击外部关闭。
- 3、10、20 项任务均可浏览、勾选、撤销，重启数据不丢。
- 深浅色、键盘、长文本、多显示器和 VoiceOver 基本操作可用。
- 没有 Start Focus、计时、桌宠元素。

### M1 · 本地任务闭环
交付：Goal、Task、RoutineRule、DailyPlan、UserOverride、Quick Capture、本地历史/跨日处理；编辑、推迟、删除及合并规则。

验收：
- 今天删除或推迟的任务，同一天刷新不重新出现。
- Routine 昨日完成后次日生成新实例，今天不能自动显示已完成。
- 手动编辑后的标题刷新不变。
- Mac 关闭再开、睡眠跨日、换时区场景不会生成重复任务。
- 本地空数据时显示真实空状态。

### M2 · 规则自动规划 + 可选 AI
交付：数据归一化、硬约束、候选评分、分组排序、可选 AI provider、schema 校验、推荐理由和基于确定性规则的降级。

验收：
- 禁用 AI 仍能生成并展示合理的本地规则清单。
- 模型输出不合法/虚构 deadline 被拒绝，原清单不受破坏。
- 同样输入连续刷新不会不合理改变排序、任务标题和完成状态。
- 用户明确 Must Do 不被低优先级候选取代；不强行凑足任务数。
- 模型断网、无额度、密钥错误时，不阻塞核心任务功能。

### M3 · 真正的数据输入
交付：macOS Calendar 读取与选日历、GitHub read-only 连接与选仓库、源健康状态、增量刷新/去重、安全配置。

验收：
- 权限开启后读取实际选定数据；不读取未选定仓库/日历。
- 取消日历权限时停止读取，核心任务仍可使用。
- PR、Issue、日历事件不被直接视为今日必须完成。
- 重复同步不会制造重复任务，不会覆盖用户手动修改。
- 令牌存 Keychain，日志/仓库无凭证；API 速率限制可正确降级。

### M4 · 真机打磨与发布准备
交付：登录启动、节能调度、异常状态、UI 调优、全面无障碍检查、系统兼容验证、打包和安装文档。

验收：
- Mac 登录和唤醒后按规则检查新日计划，不在关机期间作不可能的实时更新承诺。
- 断网可打开缓存、修改任务，网络恢复后安全合并。
- Settings 与 Quit 无隐藏窗口/agent app 死角。
- 无高频后台 CPU/网络异常；可解释刷新时间与状态。
- 在目标 macOS 版本的真实硬件上做连续 7 天使用测试。

## 2. 强制测试矩阵

| 测试类 | 用例 |
| --- | --- |
| 单元测试 | score、硬约束、分组、去重、用户覆盖、日期计算、RoutineRule |
| 属性/不变量测试 | Done 不自动撤销；Dismissed 不重现；相同来源 ID 只出现一次 |
| 协议/模型测试 | LLM schema 错误、无效候选 ID、臆造 Deadline、提示注入 |
| 数据集成测试 | GitHub 429、403、401、分页、空结果、部分失败 |
| 系统集成测试 | EventKit 授权、撤销、重复实例、只读使用 |
| 持久化测试 | 崩溃恢复、事务一致性、重启后完成状态、迁移 |
| UI 测试 | 0/1/3/20/50 项、长标题、中英文、Dark、Reduce Motion |
| 辅助功能测试 | VoiceOver、Tab/Space/Enter/Esc、对比度、缩放 |
| 生命周期测试 | 午夜、睡眠唤醒、时区变更、登录启动、多屏 |
| 隐私安全测试 | Keychain、最小权限、日志脱敏、源授权白名单 |

## 3. 设计审计清单（Release Gate）

- [ ] 所有一级 UI 都能解释业务价值；没有无意义的标签/图标/进度彩条。
- [ ] 菜单栏图标清楚、不抢位置，与系统 Light/Dark 状态协调。
- [ ] 在系统默认文字大小下，360pt 面板的布局不拥挤。
- [ ] 20 条任务时只滚动列表，Header 和添加入口可用。
- [ ] 完成任务不会导致正在操作的行突然消失或丢失键盘焦点。
- [ ] 右键菜单、快捷添加和设置都遵循 macOS 操作习惯。
- [ ] 从任何数据故障都能读到上一份可信清单。
- [ ] 每条系统建议都能解释来源，不能自称有不存在的 Deadline。
- [ ] 不依赖模型才能勾选、编辑或保存任务。
- [ ] 不含桌宠、Start Focus、计时器、番茄钟或专注统计。

## 4. MVP 产品指标（需真实使用测量）

- 每日人工维护时间中位数 ≤ 1 分钟。
- 推荐任务有价值比例 ≥ 80%。
- 确认的 AI 虚构 Deadline 数 = 0。
- 同步覆盖用户完成/编辑/推迟状态的次数 = 0。
- 断网可用性：本地清单读取/修改/保存正常。
- 日计划重复生成率 = 0。

以上是**提议的验收目标**，不是现有产品的测量结果。

## 5. 交付规则

- 每个里程碑都提交可编译工程与测试证据（具体 Xcode 版本、macOS 版本、测试命令、结果）。
- 若某项不可在当前环境验证，应标为 NOT_TESTED，不能写 PASS。
- 文档与实际实现不符时更新 ADR/文档并解释，不允许无记录地改变“只做清单”边界。
- 若首版集成需要临时 mock，必须清楚标注并在联调结束时删除虚构生产数据。
- 公开仓库添加自动构建时优先 macOS Runner，避免在 CI 中依赖个人 GitHub/AI 凭证。
