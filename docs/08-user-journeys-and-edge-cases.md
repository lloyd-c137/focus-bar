# 08 · 用户流程与边界场景

Focus Bar V1：纯本地、手动录入的 macOS 菜单栏每日事项清单。

## 1. 第一次打开

1. 用户启动应用，菜单栏出现 Focus Bar 单色符号。
2. 点击菜单栏，显示 `Today` 和当前本地日期。
3. 尚无事项时，面板显示 `Nothing scheduled for today.` 和 `+ Add a task`。
4. 用户点击 Add，输入 `完成今日作业`，点击回车，任务立即保存并显示。
5. 用户无需注册、导入日历、连接 GitHub、填写 AI Key 或授权其他应用。
6. 用户可选择登录时启动；默认是否自动开启以发行版配置为准，设置项必须可见。

**失败案例**：SwiftData 初始化失败时提供可理解的错误/恢复选项，不把真实空数据库状态与加载失败混淆。

## 2. 安排明天的事情

1. 点击日期，选择 Tomorrow。
2. 点击 Add，输入标题，默认日期即 Tomorrow。
3. 用户可选 10:30 作为计划时间，也可以保持 Anytime。
4. 保存后 Tomorrow 可见，Today 不可见。
5. 返回 Today 不会改变明日安排。

**边界**：切换日期只能修改查看条件，不应修改现有任务的原定日期。

## 3. 添加当天有时间的安排

1. Today 中点击 Add，输入标题。
2. 按需要展开日期/时间输入，选择今天 15:00。
3. 保存后该任务出现在 Scheduled，按时刻升序排列。
4. 没有时间的任务留在 Anytime。

**边界**：时间是事项的计划时刻，不是独立 Deadline；不触发提醒或警报（V1 不提供通知功能）。

## 4. 完成和撤销

1. 点击任务前的复选框。
2. 数据库提交成功后，任务进入 Completed 折叠区。
3. 展开 Completed 可撤销完成。
4. 重启 Mac 或应用，状态保持不变。

**边界**：保存失败不能显示永久完成状态；不得将完成解释为删除任务。

## 5. 昨天遗漏

1. 昨天创建的单次任务没有勾选。
2. 今天打开 Today，在 Overdue 分区仍可看到。
3. 用户可以勾选完成，也可选择 Move to Tomorrow。
4. 只有用户主动改期，才修改任务的 scheduledDate。

**边界**：每日/每周重复事项不自动累积历史漏做实例到 Today，防止出现无限旧账。

## 6. 每日重复

1. 新增 `阅读 30 分钟`，选择 Repeat: Daily。
2. 今天勾选完成，仅记录今天这一实例。
3. 明天再次显示为未完成。
4. 用户修改某一日的标题时，只改变当前 occurrence；若修改整个系列，应明确询问作用范围。

**边界**：频率变化不能删除已经记录的历史完成状态。

## 7. 大量事项

- 0 项：空状态与清晰新增入口。
- 1–5 项：紧凑自然排版。
- 20–50 项：面板最大高度受限，任务区滚动，日期导航与 Add 仍可访问。
- 长中文标题：换行最多两行，编辑时可查看完整内容。
- 12/24 小时制：遵循系统 Locale。
- 多屏/菜单栏隐藏：面板仍附着当前菜单栏入口并保持屏幕边界内。

## 8. 系统与数据异常

| 场景 | 预期 |
| --- | --- |
| 离线 | 一切核心操作照常 |
| 睡眠跨日 | 唤醒后重新计算 Today/Overdue |
| 改系统时区 | 用户设置的日历日期保持不变 |
| 输入法组合态按 Enter | 只确认候选文字，不提交完整任务 |
| 数据库写入失败 | 保留输入内容，提示保存失败 |
| 误删 | 原生 Undo 或确认操作 |
| 连续快速勾选 | 最终状态准确，无竞态覆盖 |
| 多次打开菜单栏 | 不生成重复任务 |
| 辅助功能开启 | VoiceOver 正确读取标题、日期和状态 |
| 关闭面板 | 应用继续运行，数据保存 |

## 9. 用户可见文字

产品以中英文可本地化为目标。推荐文案简洁克制：
- Today / 今天
- Tomorrow / 明天
- Overdue / 已逾期
- Anytime / 不限时间
- Completed / 已完成
- Add a task / 添加事项
- Nothing scheduled for today. / 今天还没有安排
- Unable to save. Try again. / 保存失败，请重试

避免“你今天必须努力”“快去完成”等训诫式文案。
